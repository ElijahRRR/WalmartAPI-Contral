语义① 运行结局 —— 五种,不是两种

成功 · 退出码 0失败 · 退出码 1忙 · 退出码 3,上一轮还在跑 结局不确定 · feed Unknown配置错 · 退出码 2
忙用石板灰、不许红 —— 染红的话「它正忙」和「它坏了」混为一谈,人会天天去查一个没坏的东西。
「结局不确定」用琥珀空心点(实心 = 已落定):它既不是成功也不是失败,系统的处理是不重复提交、等自愈链收尾。

语义② 按钮三档 + 危险的形状

查询导出 CSV同步 UPC 确认执行
查询导出运行 执行 对照:危险按钮(红实心块 + ⚡)vs 失败徽章(红点 + 文字)→ 失败拒绝
危险按钮与失败徽章同色相,靠形状 + ⚡ 图标区分。危险按钮永远先出现「预览」那一步,不给直达;只读动作用幽灵按钮,常规写入用黑实心。

语义③ 中间态 vs 终态

终态(实心) approvedrejectedconfirmedwithdrawndone✓ 通过建议拒绝
中间态(虚线) pendingexecutingUnknownsuggested待人工
pending / executing / Unknown 都是还没完,不配与 approved / done 相同的视觉重量:浅底 + 虚线描边,且列表里可一键筛出。
